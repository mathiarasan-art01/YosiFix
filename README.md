# 🌟 Overview

**YosiFix (Your Opportunity, Solution & Innovation Fix)** is an AI-powered research and innovation platform that transforms raw project ideas into **evidence-backed, UN SDG-aligned, technically validated, hackathon-ready project blueprints**.

Instead of immediately coding an idea, YosiFix performs deep research, similarity detection, innovation gap analysis, technology recommendation, architecture generation, and roadmap creation.

Designed for:

* 🎓 Students
* 🧑‍💻 Developers
* 🏆 Hackathon Teams
* 📚 Researchers
* 🚀 Startups & Innovators

---

# 🚀 Quick Start

## 1️⃣ Clone Repository

```bash
git clone https://github.com/YOUR_USERNAME/yosifix.git

cd yosifix
```

---

## 2️⃣ Frontend

```bash
cd frontend

npm install

npm run dev
```

Frontend runs at:

```text
http://localhost:3000
```

---

## 3️⃣ Backend

Create Virtual Environment

```bash
cd backend

python -m venv .venv
```

Activate

### Windows

```powershell
.venv\Scripts\activate
```

### macOS/Linux

```bash
source .venv/bin/activate
```

Install Packages

```bash
pip install -r requirements.txt
```

Run FastAPI

```bash
uvicorn main:app --reload --port 8000
```

Swagger Documentation

```text
http://localhost:8000/docs
```

Stop

docker compose down
